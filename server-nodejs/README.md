# Pixel Vault API

Servidor NodeJS sin dependencias externas para el proyecto Flutter de videojuegos retro.

## Ejecutar

```bash
cd server-nodejs
npm start
```

El servidor se abre en:

```txt
http://localhost:3000
```

## Endpoints

- `POST /categories`
- `POST /games/by-category`
- `POST /games/detail`
- `POST /games/search`
- `GET /images/:filename`
